# Returns and refunds

## Return window
Unworn items can be returned within 30 days of delivery. Sale items marked final sale cannot be returned.

## How to start a return
Open your order in the account page and choose Start a return. Print the prepaid label and drop the parcel at any partner post office.

## Refunds
Refunds go back to the original payment method within 5 to 7 business days after the warehouse receives the return. Original shipping fees are not refunded.

## Exchanges
To exchange a size, return the item and place a new order. This is the fastest way to get the new size.
